About me

I build web interfaces that work for everyone — including people using screen readers, keyboards and slow connections.

I’m a software builder based in Islamabad, Pakistan. My work centres on semantic HTML, WCAG-compliant interaction design and measurable front-end performance. I care about markup that describes meaning rather than appearance, because that is what makes a page usable by assistive technology, search engines and future maintainers alike.

Currently I’m completing an internship focused on accessibility engineering, where I audit interfaces against WCAG 2.1 AA and rebuild them on a clean semantic foundation.

Skills

  • Markup & standards

    Semantic HTML5, ARIA authoring practices, W3C validation, progressive enhancement.

  • Accessibility

    WCAG 2.1 AA audits, keyboard interaction design, screen-reader testing with NVDA and VoiceOver.

  • Styling

    Modern CSS, Flexbox and Grid, responsive and print layouts, reduced-motion and contrast preferences.

  • Performance & SEO

    Core Web Vitals, responsive images, structured data, Lighthouse and axe DevTools.
