Projects

A selection of work focused on accessibility, semantic structure and performance.

Accessible Dashboard UI

  • HTML5
  • ARIA
  • CSS Grid

An analytics dashboard rebuilt from a div-heavy prototype into landmark-based semantic regions. Charts expose accessible data tables, asynchronous updates are announced through polite live regions, and every control is reachable in a logical tab order.

Outcome: Lighthouse Accessibility 100, zero axe DevTools violations.

Semantic Blog Engine

  • Static site
  • SEO
  • JSON-LD

A static generator that emits article markup with correct heading hierarchy, canonical URLs, Open Graph tags and Article structured data. Output pages ship no client-side JavaScript by default.

Outcome: Lighthouse SEO 100 across all generated pages.

Form Validation Library

  • JavaScript
  • a11y
  • Zero deps

A dependency-free helper that layers on the native Constraint Validation API. Errors are linked to inputs with aria-describedby, flagged with aria-invalid and announced through an assertive live region, and focus moves to the first invalid field on submit.

Outcome: Under 3 KB gzipped, fully keyboard and screen-reader tested.
